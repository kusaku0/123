# Ценник — сравнение цен на веб-странице

Поиск по названию на WB, Ozon, AliExpress и Avito, с настройкой на **Липецк**. Результаты открываются в обычном браузере, в том числе на телефоне. **Telegram, токен бота, VPN и пользовательский SOCKS5-прокси для сайта не нужны.**

Сайт показывает до трёх предложений от каждой площадки, сортирует найденные цены по возрастанию, даёт ссылки на товар и отдельный статус каждого магазина. При блокировке одной площадки результаты остальных сохраняются. Доставка в сравнение не включена; объявления Avito могут быть о новых и подержанных товарах.

## Простой запуск на Windows

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Распакуйте архив через **«Извлечь всё»**; не запускайте файлы прямо внутри ZIP.
3. Если Python ещё не установлен, установите **Python 3.11 или новее** с [python.org](https://www.python.org/downloads/) и включите **Add Python to PATH**.
4. В распакованной папке дважды нажмите **START-WINDOWS.bat**.

Первый запуск установит зависимости и Chromium, затем откроет сайт в браузере. Чёрное окно оставьте открытым. Для остановки нажмите Ctrl+C. Токен Telegram не нужен. Запуск Windows-файла подготовлен, но в этой Linux-среде не проверен на Windows.

### Если сайты открываются вручную, а программа получает отказ

При запуске через `START-WINDOWS.bat` теперь включается **локальный браузерный режим**. Во время поиска открывается отдельное окно Chromium с вкладками магазинов. Его сессия сохраняется между поисками и перезапусками в `.pricebot/browser`. Это отдельный профиль программы; ваш личный профиль Chrome не используется.

Если площадка просит проверку, нажмите в её карточке **«Открыть окно магазина»**, выполните проверку вручную в открывшемся окне и снова нажмите **«Найти дешевле»** на странице программы. Не закрывайте окно Chromium во время проверки. Повторный поиск после открытия окна обновляет результат без старого кэша.

Обычная ссылка **«Открыть поиск»** ведёт в ваш привычный браузер. Его сессия отличается от сессии программы: проверка там не переносится в Chromium автоматически. Для повторного автоматического поиска используйте именно **«Открыть окно магазина»**.

Для WB в локальном режиме читаются только данные публичного каталога, полученные самой открытой страницей поиска. Никакие cookies не копируются в отдельный HTTP-клиент. Валюта запроса должна быть RUB; регион доставки подтверждайте на площадке. Формат данных всё ещё может измениться.

**Сохранение сессии не гарантирует снятие ограничений.** Если сайт не разрешает автоматизированный браузер даже после ручной проверки, кнопка это не обойдёт. Для AliExpress отсутствие распознанных цен также может означать изменение страницы или другую валюту. Проверки живых сайтов из этой облачной среды по-прежнему ограничены сетью.

Чтобы обновить программу, остановите старое чёрное окно, скачайте свежий ZIP, распакуйте его и запустите новый `START-WINDOWS.bat`. Не запускайте старую и новую копию одновременно на порту 8000. Папка `.pricebot` содержит состояние браузера: не публикуйте и не присылайте её.

Если сайт не открылся или окно сообщает об ошибке, сохраните скриншот сообщения. Не открывайте `index.html` отдельно: ему нужен запущенный сервер. Виртуальная среда `.venv` создаётся в папке программы; зависимости устанавливаются по зафиксированным версиям и SHA-256.

## Запуск через терминал

Нужны Python 3.11+, [uv](https://docs.astral.sh/uv/getting-started/installation/) и Chromium.

```bash
cd /workspace/123  # или каталог проекта на вашем компьютере
uv sync --frozen --extra dev
uv run playwright install chromium
uv run priceweb --check
uv run priceweb
```

`priceweb` запускает сайт на вашем компьютере, порт **8000**. При локальном запуске откройте в браузере localhost с портом 8000. Остановка — `Ctrl+C`. Не открывайте HTML двойным кликом: страница обращается к API запущенного сервера.

Если системный `chromium` или `chromium-browser` уже есть, скачивать браузер не нужно. На Linux при отсутствии системных библиотек выполните `uv run playwright install --with-deps chromium` с необходимыми правами. Проверка `--check` запускает локальную страницу, но не проверяет доступ к магазинам.

`.env` необязателен: по умолчанию уже установлены Липецк и рубли. Для изменения параметров скопируйте `.env.example` в `.env`. `BOT_TOKEN` оставьте пустым: сайт его не использует.

Для запуска вручную на ПК можно установить `LOCAL_BROWSER_MODE=true` в `.env`. На сервере без рабочего стола оставьте `false`: браузерное окно открывается на машине с программой, а не у посетителя сайта. API открытия окна доступно только с loopback-адреса этого компьютера; запросы с других адресов/внешних сайтов отклоняются.

## Открыть с телефона или другого компьютера

```bash
uv run priceweb --host 0.0.0.0 --port 8000
```

В одной домашней сети используйте локальный IP компьютера с портом 8000. Компьютер с программой должен оставаться включённым, а его сетевые настройки должны разрешать доступ к этому порту.

Для доступа из интернета разместите приложение на сервере с обычным доступом к маркетплейсам и настройте домен/HTTPS в своём хостинге или обратном прокси. `0.0.0.0` — адрес прослушивания, а не ссылка для открытия. Приложение подготовлено; публичный домен и внешний хостинг не созданы. Сайт публичный, без регистрации; личный доступ можно ограничить средствами хостинга. Кэш и ограничение одновременных поисков действуют в одном процессе, поэтому запускайте один процесс Uvicorn.

## Работа без VPN

Браузер пользователя обращается только к вашему сайту. К магазинам обращается сервер; поэтому приложению не нужен доступ к Telegram. Шрифты, стили и JavaScript хранятся в проекте, внешние CDN для интерфейса не требуются.

**Работа всех четырёх маркетплейсов без блокировок не гарантируется.** Они могут ограничивать адреса дата-центров, менять страницы, требовать вход или CAPTCHA. Обычный Chromium это ограничение не снимает. Сайт не решает CAPTCHA и не подменяет сетевое расположение. Если магазин недоступен, страница покажет статус и ссылку на ручной поиск.

Варианты без собственного VPN/прокси: домашний ПК с прямым доступом к магазинам или сервер, с которого они доступны напрямую. Проверяйте доступ до оплаты хостинга. Если ни один подходящий адрес не даёт доступ, понадобится разрешённый источник данных/партнёрский API или ручной поиск.

В этой облачной среде реальные запросы к магазинам запрещены сетевым прокси. Локальные тесты и работа интерфейса не подтверждают доступность живых цен из другой сети.

## Точность сравнения

- WB: публичный JSON поиска, обычная цена доступного размера без скидки кошелька. Регион определяется по координатам Липецка; при неудаче показывается предупреждение. Для точного пункта выдачи можно указать `WB_DEST`.
- Ozon, AliExpress, Avito: обычная страница поиска в Chromium; читаются структурированные данные и карточки. Для Avito город указан в URL. Регион доставки Ozon/AliExpress нужно подтвердить при оформлении.
- Сравниваются положительные цены в рублях на первой доступной странице, а не весь каталог. Валюта не конвертируется; распознанные диапазоны, отсутствие товара и реклама отбрасываются.
- Фильтр проверяет слова запроса и отсеивает очевидные аксессуары для устройств. Он не гарантирует одинаковую модель, комплектацию и состояние. Мошеннические объявления и символические цены полностью распознать нельзя.
- Цена Ozon может требовать карту Ozon, а AliExpress — купон или статус нового покупателя. Итоговую сумму, условия, доставку и наличие проверяйте на площадке.
- Кэш — до 3 минут, одновременных поисков — 2. Изменяются через `CACHE_TTL` и `MAX_CONCURRENT_SEARCHES`. Уведомление об ошибке магазина отличается от пустой выдачи.

## API и проверки

- `GET /` — интерфейс.
- `GET /api/health` — сервер отвечает; не проверяет площадки.
- `POST /api/search`, JSON `{"query":"iPhone 15 128 GB"}` — результаты и статусы магазинов.
- Неверный запрос — HTTP 422; заняты слоты поиска — 429; внутренняя ошибка — 503 без раскрытия деталей.

```bash
uv run pytest -q
uv run priceweb --check
# Живой поиск из терминала без Telegram-токена:
uv run pricebot --search "iPhone 15"
```

Тесты парсеров и API используют подготовленные ответы и проверяют цены, валюты, ссылки, блокировки, частичные результаты, валидацию и конкурентные запросы. Проверки интерфейса не добавляют демонстрационные цены в рабочее приложение. Живой терминальный поиск завершится с кодом 2, если не получил подтверждённых предложений.

## Сетевая политика облака

При ограничении исходящих запросов нужны `search.wb.ru`, `user-geo-data.wildberries.ru`, `ozon.ru`/`*.ozon.ru`/`*.ozone.ru`, `avito.ru`/`*.avito.ru`/`*.avito.st`, `aliexpress.ru`/`*.aliexpress.ru`, `aliexpress.com`/`*.aliexpress.com`, `*.alicdn.com`. Дополнительные домены могут понадобиться при изменениях площадок. Проверка TLS сохраняется. Штатные сетевые настройки платформы используются как предоставлены; это не требование покупать свой прокси.

## Необязательный прежний Telegram-режим

Сохранён отдельной командой `uv run pricebot`. Для него нужны `BOT_TOKEN` и доступ к Telegram; рекомендуется `ALLOWED_USER_IDS`. Для работы сайта этот режим запускать не нужно.
